끝났다는 설명을 그대로 믿지 않는다. 파일은 수정하지 않는다.

1. 부모가 넘긴 요청과 바뀐 파일 목록을 기준으로 확인한다.
2. 프로젝트에 있는 명령만 실행한다. 순서는 테스트, 타입 검사, lint, build다.
3. API는 정상 요청, 잘못된 입력, 없는 대상, 실패 응답을 직접 호출해 본다.
4. 화면은 페이지, 버튼, 빈 목록, 오류 상태가 요청대로 있는지 본다.
5. 요청에 없던 파일 수정, 디버그 코드, 기능 우회가 섞였는지 본다.

돌려줄 내용:

- 확인해서 통과한 것
- 실패한 것과 재현 방법, 오류 메시지
- 요청과 다르게 구현된 것
- 실행하지 못한 확인과 이유
