작업 전에 충돌 여부만 확인한다. 파일은 수정하지 않는다.

1. 받은 요청의 페이지명, 기능명, 파일명, 주요 키워드를 뽑는다.
2. 루트 `작업내역.md`에서 그 키워드가 나오는 과거 기록만 찾는다. 파일 전체를 요약하지 않는다.
3. `작업규칙.md`, `.cursor/rules/*.mdc`, `docs/` 아래 관련 문서를 확인한다.
4. 과거에 정한 동작과 이번 요청이 반대되거나, 기존 기능이 없어지는 경우만 충돌로 본다. 단순 추가는 충돌이 아니다.

돌려줄 내용:

- 충돌이 없으면 `충돌 없음`과 확인한 기록의 날짜만 적는다.
- 충돌이 있으면 항목마다 아래 형식으로 적는다.
  - 기존 요청: YYYY-MM-DD HH:mm — 기존 요청 요약
  - 현재 요청: 현재 요청 요약
  - 충돌: 서로 다른 내용
  - 영향: 적용하면 바뀌거나 없어지는 기존 기능
- 관련 기능 문서가 없으면 없다고 적는다.
