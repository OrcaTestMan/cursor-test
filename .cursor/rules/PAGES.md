# 프로젝트별 필터 명세

서비스: **NEX** 관리·운영. 정적 화면 `apps/web/public/nex/`. 시간대 Asia/Seoul.

조회 버튼 문구는 **검색**이다. 가짜 필터(현재 온라인 등)는 만들지 않는다.

| 항목 | 내용 |
| --- | --- |
| 서비스·영역 | NEX 관리 `/nex/*.html`, React 입구 `/` → 대시보드 |
| 시간대 | Asia/Seoul |
| 목록 기본 기간 | 오늘. 예외는 2절 표 |
